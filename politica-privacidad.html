Política de Privacidad

La aplicación Amari API utiliza la API de Google Drive únicamente para almacenar, consultar y eliminar archivos dentro de una carpeta propia del servicio.

La aplicación no recopila, almacena ni comparte datos personales de los usuarios. Los permisos otorgados se usan exclusivamente para el funcionamiento del servicio.
